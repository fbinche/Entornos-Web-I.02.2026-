# Desarrollo Web – Material de Clase

Repositorio utilizado en el curso **Desarrollo Web – Sección I.02.2026-I (Ate)**.
Este repositorio contiene ejemplos, ejercicios y material utilizado durante las sesiones prácticas del curso.

---

## 📚 Objetivo del repositorio

Proporcionar a los estudiantes ejemplos prácticos para aprender y reforzar conceptos fundamentales del desarrollo web:

* HTML
* CSS
* Bootstrap
* Estructura de proyectos web
* Buenas prácticas de maquetación y organización de código

El repositorio se actualiza conforme avanzan las clases.

---

## 📂 Estructura del proyecto

| Carpeta / Archivo      | Tipo          | Descripción                                                                                                      |
| ---------------------- | ------------- | ---------------------------------------------------------------------------------------------------------------- |
| `assets/`              | Carpeta       | Contiene recursos utilizados en los ejemplos como archivos CSS, JavaScript, imágenes y otros recursos estáticos. |
| `class/`               | Carpeta       | Archivos utilizados durante las sesiones de clase para explicar conceptos y realizar demostraciones.             |
| `pages/`               | Carpeta       | Páginas web de ejemplo que muestran implementaciones completas o parciales vistas en el curso.                   |
| `examples/`            | Carpeta       | Ejemplos adicionales del framework Bootstrap utilizados como referencia para el diseño de interfaces.            |
| `clases_HTML.html`     | Archivo       | Ejemplos de etiquetas HTML y estructura básica de documentos web.                                                |
| `clases_CSS.html`      | Archivo       | Ejemplos de aplicación de estilos CSS para diseño y maquetación.                                                 |
| `clases_Boostrap.html` | Archivo       | Ejemplos de componentes y utilidades del framework Bootstrap utilizados en clase.                                |
| `formulario.html`      | Archivo       | Ejemplo de estructura de formularios HTML.                                                                       |
| `demo.html`            | Archivo       | Página de demostración con ejemplos aplicados.                                                                   |
| `index.html`           | Archivo       | Página principal del proyecto utilizada como punto de entrada para los ejemplos.                                 |
| `.gitignore`           | Configuración | Define los archivos o carpetas que Git debe ignorar.                                                             |
| `package.json`         | Configuración | Archivo de dependencias del proyecto (por ejemplo Bootstrap Icons).                                              |
| `package-lock.json`    | Configuración | Registro automático de versiones de dependencias instaladas.                                                     |

---

## 🚀 Cómo usar este repositorio

1. Clonar el repositorio:

```bash
git clone <url-del-repositorio>
```

2. Abrir la carpeta del proyecto en **Visual Studio Code** u otro editor de código.

3. Abrir cualquier archivo `.html` en el navegador para visualizar los ejemplos.

---

## 💡 Recomendaciones para estudiantes

* Revisar los ejemplos después de cada clase.
* Analizar la estructura del código antes de modificarlo.
* Realizar pruebas cambiando el código para comprender mejor el funcionamiento de HTML, CSS y Bootstrap.
* Utilizar este repositorio como referencia para tareas y ejercicios del curso.
